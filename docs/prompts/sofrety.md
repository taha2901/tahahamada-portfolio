# برومبت مشروع سفرتي (food_delivery_app)

افتح Claude Code في المسار ده:

```
d:\Flutter Apps\my real projects\food_delivery_app
```

وانسخله البلوك اللي تحت كامل.

---

```
اقرأ المشروع ده كله الأول، وبعدين جهّزلي مادة كاملة عشان أعرضه في البورتفوليو بتاعي
كـ Case Study محترمة. المطلوب حاجتين: لقطات شاشة منظّمة + ملف محتوى شامل.

المشروع ده تطبيق توصيل طعام اسمه "سفرتي / Sofrety" مبني بـ Flutter، وفيه
Bloc/Cubit و Firebase و OpenStreetMap وبوابة دفع. الشاشات اللي شفتها في lib/features:
splash / login / register / home / restaurant / search / cart / orders / chat /
favorites / profile / payment — أكّد بنفسك من الكود ولو في شاشات تانية ضيفها.

اشتغل بالترتيب ده:

═══════════════════════════════════════════
1) افهم المشروع فعليًا
═══════════════════════════════════════════
• اقرأ الكود كله: الـ features، الـ viewmodels/cubits، طبقة الـ data، والـ core.
• اطلعلي بقائمة بكل شاشة وإيه اللي بتعمله بالظبط.
• حدّد إيه اللي متعمول فعلًا وإيه اللي ناقص أو نصف شغّال — ده مهم جدًا، أنا مش عايز
  أكتب في البورتفوليو حاجة مش موجودة.
• حدّد الميزات اللي فيها شغل تقني حقيقي (الخرايط، الدفع، الكاش، إدارة الحالة، الشات).

═══════════════════════════════════════════
2) جهّز بيانات تجريبية محترمة
═══════════════════════════════════════════
• مفيش شاشة فاضية ولا Loading ولا "No data" في أي لقطة.
• مطاعم وأكلات وأسعار وعناوين واقعية (مصرية)، وصور أكل حقيقية مش placeholder رمادي.
• السلة تبقى فيها 2–3 أصناف بكميات مختلفة، والطلبات فيها طلب شغّال وطلب متسلّم.
• ثبّت نفس المستخدم ونفس العنوان ونفس التاريخ في كل اللقطات عشان يبانوا من جلسة واحدة.
• متستخدمش أي بيانات حقيقية (تليفونات، إيميلات، عناوين حقيقية) — كله مولّد.
• لو التطبيق بيحتاج تسجيل دخول، اعمل حساب تجريبي وقوللي بياناته في الآخر.

═══════════════════════════════════════════
3) صوّر اللقطات (موبايل — طولي)
═══════════════════════════════════════════
• شغّل على Android emulator بمقاس ثابت 1080×2340 (أو 1170×2532)، ونفس المقاس لكل اللقطات.
• صوّر بـ: adb exec-out screencap -p > <filename>.png
• قبل التصوير نضّف شريط الحالة بأوامر الـ demo mode عشان اللقطات تبقى شكلها احترافي:
    adb shell settings put global sysui_demo_allowed 1
    adb shell am broadcast -a com.android.systemui.demo -e command clock -e hhmm 1200
    adb shell am broadcast -a com.android.systemui.demo -e command battery -e level 100 -e plugged false
    adb shell am broadcast -a com.android.systemui.demo -e command network -e wifi show -e level 4
    adb shell am broadcast -a com.android.systemui.demo -e command notifications -e visible false
  (وفي الآخر: adb shell am broadcast -a com.android.systemui.demo -e command exit)
• نفس الثيم في كل اللقطات (متخلطش دارك ولايت).
• PNG محسّنة الحجم — كل صورة يفضل تحت 400KB.
• لو في نافذة/bottom sheet مهمة، صوّرها وهي مفتوحة فوق الشاشة اللي وراها.

اللقطات المطلوبة (قرابة 12–14 لقطة، عدّل الترتيب لو في شاشة أهم):
  01-home                الشاشة الرئيسية — المطاعم والتصنيفات (دي صورة الغلاف، خليها أقوى لقطة)
  02-restaurant          صفحة المطعم وقائمة الأكلات
  03-meal-details        تفاصيل الوجبة والإضافات
  04-cart                السلة بأصناف وحساب الإجمالي
  05-address-map         اختيار عنوان التوصيل على الخريطة (OSM)
  06-checkout            مراجعة الطلب قبل الدفع
  07-payment             شاشة الدفع وبيانات الكارت
  08-order-tracking      متابعة حالة الطلب
  09-chat                الشات مع المندوب/المطعم
  10-search              البحث والفلاتر
  11-favorites           المفضلة
  12-profile             الملف الشخصي والإعدادات
  13-login               تسجيل الدخول
  14-splash              شاشة البداية

حطهم كلهم في مجلد `portfolio-shots/` في جذر المشروع بالأسماء دي بالظبط + امتداد .png

═══════════════════════════════════════════
4) ملف portfolio-shots/portfolio.md
═══════════════════════════════════════════
اكتب فيه الحاجات دي، وكل حاجة **بالعربي والإنجليزي** مع بعض:

أ)  اسم المشروع الطويل + اسم مختصر للكارت.
ب)  وصف قصير للكارت (حوالي 30 كلمة).
ج)  وصف أطول لصفحة التفاصيل (3–4 أسطر).
د)  نبذة عن المشروع (فقرتين): المعمارية، إدارة الحالة، طبقة البيانات، الشكل العام.
هـ) المشكلة اللي بيحلها (2–3 فقرات) — ابدأ بمشكلة حقيقية في السوق مش بقايمة مميزات.
و)  دوري في المشروع (فقرة): عملت إيه بالظبط، وإيه اللي جه من باك اند جاهز أو خدمة خارجية.
ز)  التحديات وأصعب جزء تقني (فقرتين) — من واقع الكود مش كلام عام.
ح)  المميزات الرئيسية: 12–16 ميزة، كل واحدة بالشكل ده بالظبط:
        <إيموجي> <عنوان قصير> — <شرح سطر أو اتنين>
    مثال: 🗺 اختيار العنوان على الخريطة — تحديد موقع التوصيل بدقة عبر OpenStreetMap مع حفظ العناوين المتكررة.
ط)  التقنيات مقسّمة لمجموعات، مثلًا:
        الواجهة / إدارة الحالة / الشبكة والبيانات / الخرايط والدفع / الأدوات
ي)  كابشن لكل لقطة بالترتيب بالعربي والإنجليزي، وجنبه اسم الملف.
ك)  الروابط: رابط الريبو، لينك الـ APK، لينك فيديو الديمو — لو موجودين في README خدهم منه.
ل)  الحالة المناسبة للمشروع: Production / Live Demo / Offline / Design Only + جملة توضّحها.

═══════════════════════════════════════════
5) أرقام المشروع (بأوامر فعلية مش تخمين)
═══════════════════════════════════════════
احسبلي وحط جنب كل رقم الأمر اللي استخدمته:
• عدد الشاشات
• عدد الـ features/الوحدات
• عدد ملفات Dart
• عدد أسطر الكود
• عدد الـ Widgets
• عدد الـ Cubits/ViewModels
• عدد الاختبارات الآلية (لو مفيش قول "لا يوجد" بصراحة)
• أي رقم تاني مميز في المشروع ده
لو رقم مش متاح اكتب "غير متاح" — بلاش تقديرات.

═══════════════════════════════════════════
ملاحظات أخيرة مهمة
═══════════════════════════════════════════
• متكتبش أي ميزة مش موجودة فعلًا في الكود. لو حاجة نصف مكتملة قول كده صراحة في الملف.
• لو مقدرتش تصوّر شاشة معيّنة (محتاجة باك اند شغّال مثلًا)، قوللي الشاشة وليه وكمّل الباقي.
• في الآخر اعرضلي قائمة بكل الملفات اللي اتولدت وحجم كل واحد.
```

## بعد ما تخلّص

1. أنسخ `portfolio-shots/` لـ `public/images/sofrety/`
2. أظبّط الجاليري يشتغل مع اللقطات الطولية (دلوقتي بمقاس 16:10 مناسب للديسكتوب،
   ولقطات الموبايل هتحتاج عرض مختلف عشان متتقصّش)
3. أحدّث بيانات سفرتي في [data/projects.ts](../../data/projects.ts) بالمحتوى الجديد كامل
