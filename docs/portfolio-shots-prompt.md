# برومبت تجهيز لقطات المشروع للبورتفوليو

انسخ البلوك اللي تحت وحطه لـ Claude **جوّه مجلد المشروع نفسه** (مش هنا في البورتفوليو).
هو هيطلّع مجلد `portfolio-shots/` فيه الصور + ملف `portfolio.md` فيه كل المحتوى الجاهز.
بعد كده هات المجلد ده هنا وأنا هركّب المشروع في `data/projects.ts`.

الطريقة دي هي اللي اتعملت بيها لقطات «نظام نقاط البيع» (16 لقطة، 1600×900).

---

## البرومبت (انسخ من هنا)

```
اقرأ المشروع كله الأول، وبعدين جهّزلي مادة كاملة لعرض المشروع ده في البورتفوليو بتاعي.
المطلوب حاجتين: لقطات شاشة منظّمة + ملف محتوى. اشتغل بالترتيب ده:

═══════════════════════════════════════════
1) افهم المشروع
═══════════════════════════════════════════
• اقرأ الكود واطلعلي على كل الشاشات والوحدات (features/modules) والوظائف الأساسية.
• حدّد أهم 12–18 شاشة تستحق تتعرض — بحيث اللي يشوفهم يفهم النظام كله من غير ما يشغّله.
• لازم تدخل ضمنهم: الشاشة الرئيسية/الأهم، لوحة التحكم لو موجودة، أهم نافذة (dialog)
  بتوضّح ميزة مميزة، والتقارير، والإعدادات.

═══════════════════════════════════════════
2) جهّز بيانات تجريبية محترمة
═══════════════════════════════════════════
• مفيش شاشة فاضية ومفيش "Lorem ipsum" ومفيش "Test 123" ومفيش أرقام عشوائية.
• لو التطبيق عربي: أسماء ومنتجات وأرقام واقعية بالعربي.
• ثبّت نفس التاريخ ونفس المستخدم ونفس الفرع/الحساب في كل اللقطات عشان يبانوا من جلسة واحدة.
• متعرضش أي بيانات حقيقية لعميل أو أرقام تليفونات حقيقية — كله بيانات مولّدة.

═══════════════════════════════════════════
3) صوّر اللقطات
═══════════════════════════════════════════
اختار الطريقة حسب نوع المشروع، والأهم إنها تكون قابلة للتكرار:

• تطبيق سطح مكتب / ويب (Flutter Desktop أو Web أو Next.js):
  ابنِ نسخة ويب، شغّلها محليًا، واكتب سكربت Playwright يفتح كل شاشة ويصوّرها
  بمقاس ثابت 1600×900 (deviceScaleFactor: 1). ده بيدي لقطات نضيفة ومتكررة
  من غير إطار الويندوز ومن غير مؤشر الماوس.

• تطبيق موبايل:
  شغّل على emulator بمقاس ثابت وصوّر بـ `adb exec-out screencap -p`،
  أو استخدم integration_test مع takeScreenshot.

قواعد اللقطات:
• كل اللقطات بنفس المقاس وبنفس الثيم (متخلطش دارك ولايت).
• PNG، وأقصى عرض 1600px، ومحسّنة الحجم (كل صورة يفضل تحت 300KB).
• من غير شريط عنوان الويندوز، من غير شريط المتصفح، من غير مؤشر ماوس.
• لو في نافذة/dialog، صوّرها وهي مفتوحة فوق الشاشة اللي وراها.

═══════════════════════════════════════════
4) الأسماء والمجلد
═══════════════════════════════════════════
حط كل الصور في مجلد `portfolio-shots/` في جذر المشروع، بالتسمية دي:

  01-<اسم-الشاشة>.png
  02-<اسم-الشاشة>.png
  ...

أسماء إنجليزي kebab-case وواضحة (مثال: 01-pos-cover.png، 03-payment.png).
اللقطة رقم 01 هي غلاف المشروع — خليها أقوى وأشمل لقطة عندك.

═══════════════════════════════════════════
5) ملف المحتوى portfolio-shots/portfolio.md
═══════════════════════════════════════════
اكتب فيه الحاجات دي بالعربي والإنجليزي مع بعض (كل حاجة باللغتين):

أ) العنوان: اسم طويل + اسم مختصر للكارت.
ب) وصف قصير للكارت (سطرين، حوالي 30 كلمة).
ج) وصف أطول لصفحة التفاصيل (3–4 أسطر).
د) نبذة عن المشروع (فقرتين).
هـ) المشكلة اللي بيحلها (2–3 فقرات، وابدأ بالمشكلة الحقيقية في السوق مش بمميزات التطبيق).
و) دوري في المشروع (فقرة: أنا عملت إيه بالظبط، وإيه اللي لسه قيد التطوير).
ز) التحديات وأصعب جزء تقني (فقرتين).
ح) المميزات الرئيسية: 12–18 ميزة، كل واحدة بالشكل ده بالظبط:
     <إيموجي> <عنوان قصير> — <شرح سطر أو اتنين>
ط) التقنيات مقسّمة لمجموعات (الواجهة / إدارة الحالة / المكتبات / الباك اند / DevOps).
ي) كابشن لكل لقطة بالترتيب، بالعربي والإنجليزي، وجنبه اسم الملف.
ك) الروابط المتاحة: رابط ديمو أونلاين، رابط الريبو، رابط تحميل النسخة (اكتب "لا يوجد" لو مفيش).
ل) الحالة: (Production / Live Demo / Offline / Design Only) + جملة توضّحها.

═══════════════════════════════════════════
6) أرقام المشروع (مهمة — اطلعها من الكود بأوامر فعلية مش تخمين)
═══════════════════════════════════════════
احسبلي وحطهم في آخر الملف:
• عدد الشاشات
• عدد الوحدات/الـ features المستقلة
• عدد ملفات الكود (Dart/TS)
• عدد أسطر الكود
• عدد الـ Widgets / الكومبوننتس
• عدد الـ Controllers / الـ Services
• عدد الاختبارات الآلية
• عدد التقارير أو أي رقم مميز في المشروع ده
اكتب الأمر اللي استخدمته لكل رقم جنبه، وأنا عايز أرقام حقيقية — لو رقم مش متاح قول "غير متاح".

═══════════════════════════════════════════
ملاحظات أخيرة
═══════════════════════════════════════════
• متكتبش أي حاجة مش موجودة فعلًا في الكود. لو ميزة ناقصة أو نصف مكتملة قولي كده صراحة.
• لو مقدرتش تصوّر شاشة معيّنة لأي سبب، قولي الشاشة دي وليه، وكمّل الباقي.
• في الآخر اعرضلي قائمة بأسماء الملفات اللي اتولدت وحجم كل واحد.
```

---

## بعد ما تخلّص

1. هات مجلد `portfolio-shots/` (الصور + `portfolio.md`) وقولي "ضيف المشروع ده".
2. أنا هنسخ الصور لـ `public/images/<slug>/` وأضيف المشروع في [data/projects.ts](../data/projects.ts).
3. مهم: بعد نسخ أي صور جديدة لازم **تعيد تشغيل** `npm run dev` — Next بيقرأ مجلد
   `public/` مرة واحدة عند التشغيل، وأي صورة تتضاف بعد كده بترجع 404 لحد ما تعمل restart.
